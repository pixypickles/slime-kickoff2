# スライム・キックオフ2 Prototype v0.4

GitHub Pages向けのHTML5 Canvas試作版です。外部画像・外部ライブラリは使用していません。

## v0.4の修正

- 画面全体を明るい配色へ変更
- 人間を常に左右どちらかへ向いた横向き姿勢に変更
- キックを「軸足を一歩前へ出す → 蹴り足を後ろへ振り上げる → 上半身を少し前傾 → 膝を前へ運ぶ → すねと足先を振り抜く」の順に再制作
- 格闘ゲーム風の横蹴り・下段蹴りに見えないよう、支持脚と蹴り脚を別々に制御
- 楕円形の異次元コート、村同士で少し臭う無害なスライムを押し付け合う設定を維持
- スライムはジャンプまたは蹴られた時だけ移動し、着地後は完全停止

## 操作

- PC: WASD / 矢印キーで移動、Spaceでキック
- スマホ: 左スティックで移動、右のキックボタン

## GitHub Pages

ZIPを展開し、`index.html` と `README.md` をリポジトリ直下へアップロードしてください。
