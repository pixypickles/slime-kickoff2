# スライム・キックオフ2 v1.0α

GitHub Pagesでそのまま動く、画像素材・外部ライブラリ不要のHTML5 Canvasゲームです。

## 今回の主な変更

- ユニフォームを縦ストライプからチームカラー1色へ変更
- 地上強キックを、足を後ろへ引いて下から前上方へ振り抜くサッカー型の軌道へ変更
- 強キックの飛距離と高さを微調整
- 既存の弱・強・ジャンプによる攻撃切り替えを維持
- スライムはジャンプまたは攻撃を受けた時だけ移動し、着地後は完全停止

## 操作

- 移動：左スティック / WASD / 矢印キー
- 弱攻撃：赤ボタン / Z
- 強攻撃：青ボタン / C
- ジャンプ：黄ボタン / X

## GitHub Pages

このZIPを展開し、`index.html` と `README.md` をリポジトリ直下へ置いてください。
