# スライム・キックオフ2 v1.2α

GitHub Pagesで動作する、スマートフォン対応のHTML5 Canvas試作版です。

## v1.2α の変更

- トランポリンの接触判定を見た目に合わせた楕円形へ修正
- 空中からの着地だけでなく、地上で踏み込んだ場合も跳ねるよう修正
- トランポリン着地前後に約0.28秒の専用入力猶予を追加
- トランポリン着地＋弱：片足を真下、片足を水平に伸ばした旋風回転蹴り
- トランポリン着地＋強：身体を伸ばした後方回転のサマーソルト攻撃
- 着地直前に押した弱・強入力も予約して発動
- CPUもまれにトランポリン専用技を使用

## 操作

- 移動：画面左スティック / WASD / 矢印キー
- 弱攻撃：赤ボタン / Z
- 強攻撃：青ボタン / C
- ジャンプ：黄ボタン / X

## GitHub Pages

ZIPを展開し、`index.html` と `README.md` をリポジトリ直下へアップロードしてください。
