# スライム・キックオフ2 Rebuild v0.6.5

GitHub Pages向けの単一HTML試作です。`index.html` と `README.md` をリポジトリ直下へ置いてください。

## v0.6.5 修正

- 浮いたスライムへの弱攻撃をアッパーカットからストレートへ変更
  - 拳を胸元へ引いてから、身体ごと少し踏み込み前方へ伸ばします
  - スライムを少し浮かせつつ前へ運ぶ、発生の早い攻撃です
- ジャンプ中の強攻撃を、旧「浮いたスライムへの強攻撃」の二段蹴り風ジャンプキックへ変更
- 浮いたスライムへの強攻撃を横蹴りへ変更
  - 膝を胸側へ畳む予備動作
  - 脚を横方向へ伸ばして強く押し出す動作
- 旧ジャンプ強攻撃の回転後ろ蹴りを廃止
- キャラクター、スライム、背景はCanvas描画のみ。外部画像素材なし

## 攻撃の自動切り替え

- 地上スライム＋弱：その場の素早い蹴り
- 地上スライム＋強：踏み込みキック
- 浮いたスライム＋弱：ストレート
- 浮いたスライム＋強：横蹴り
- 自分がジャンプ中＋弱：ヘディング
- 自分がジャンプ中＋強：二段蹴り風ジャンプキック

## 操作

- 移動：画面左スティック／WASD／矢印キー
- 弱攻撃：赤ボタン／Z
- 強攻撃：青ボタン／C
- ジャンプ：黄色ボタン／X
