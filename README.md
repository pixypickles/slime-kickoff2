# スライム・キックオフ2 Prototype v0.3

GitHub Pagesで動作する、画像素材・外部ライブラリ不要のHTML5 Canvas試作です。

## v0.3の変更
- 下段弱キック風だった脚運びを廃止
- 脚を後ろへ畳む → 膝を前へ運ぶ → すねと足先を振り抜くサッカー型キックへ変更
- キック距離とスライムの飛距離を少し抑制
- 四角いコートを、前作に近い楕円形の異次元コートへ変更
- 角をなくし、スライムが隅に固定されない構造へ変更
- CPUはスライムへ直進せず、自分側から回り込んで相手村方向を向いてから蹴る
- CPUキックに間隔を設け、連続蹴りを抑制
- 「異次元の湧き場」「無害だが少し臭いので隣村へ押しつける」という設定を画面へ反映

## 操作
- 移動: WASD / 矢印キー / 左側スティック
- キック: Space / 右側キックボタン
- 3点先取

## GitHub Pages
ZIPを展開し、`index.html` と `README.md` をリポジトリ直下へアップロードしてください。
