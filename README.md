# スライム・キックオフ2 v1.2.4α

GitHub Pagesで動作する、スマートフォン対応のHTML5 Canvas試作版です。

## 世界観

前作から数年後、競技参加者の魔法は次第にエスカレートし、スライム競技は魔法バトルのようになってしまいました。

そこで大魔導師は、コート全体をアンチマジックフィールドに指定しました。魔法による激しさが消えたあと、コートには雑草が生え始めます。

ごく稀に現れていた雲スライムは、その成分のほとんどが魔法でできていたため、アンチマジックフィールド内へ姿を現して数秒後に地面へ溶けます。なぜか、その跡は小さなトランポリンになります。

村人たちは雲スライム跡のトランポリンを利用しながら、無害だけど少し臭うスライムを隣村へ押しつけ合います。

## v1.2.4α の変更

- 石を削除
- 木を削除
- 縦長トランポリンを削除
- トランポリンの形を小型の楕円形へ統一
- コートの左右・上下へ広く分布するようトランポリンを再配置
- 草むらを少し追加
- 新しい世界観を開始画面へ反映
- トランポリン着地＋弱：片足を真下、片足を水平へ伸ばした旋風回転蹴り
- トランポリン着地＋強：身体を伸ばした後方回転のサマーソルト攻撃

## 操作

- 移動：画面左スティック / WASD / 矢印キー
- 弱攻撃：赤ボタン / Z
- 強攻撃：青ボタン / C
- ジャンプ：黄ボタン / X
