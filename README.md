# スライム・キックオフ2 Rebuild v0.6.2

GitHub Pagesでそのまま動く、1ファイル構成の試作版です。

## v0.6.2の変更

- キャラクター描画を大幅に簡略化
- 腕と脚を黒い太線へ変更
- 拳を小さな黒丸へ変更
- 靴を白い楕円＋太い黒輪郭へ変更
- 頭を丸型、顔は目だけに統一
- 胴体のみチームカラーのユニフォームとして表示
- 既存の弱・強・ジャンプと6種類の攻撃モーションは維持

## 操作

- 移動：画面左スティック／WASD／矢印キー
- 弱攻撃：赤ボタン／Z
- 強攻撃：青ボタン／C
- ジャンプ：黄ボタン／X

ZIPを展開し、`index.html` と `README.md` をGitHubリポジトリ直下へ配置してください。
