# スライム・キックオフ2 v1.4.3α

GitHub Pagesで動作する、HTML Canvas製の試作ゲームです。

## v1.4.3α の変更

- スライムモードの小ジャンプを約25%高速化
- 小ジャンプ後の待ち時間を短縮
- STEPのクールタイムを約0.24秒へ短縮
- 地上STEPではスライムが一瞬平たくなり、攻撃を避ける
- 空中STEPでは縦長に変形し、空中で1回だけ軌道を変える
- 村人の攻撃直前から命中直後までにジャンプを押すと「ジャスト跳ね返り」
- ジャスト跳ね返り成功時は被キック回数が増えず、大きく安全に跳ねる
- STEPの無敵時間は短くし、連打だけで完全無敵にならないよう調整

## スライムモード操作

- 方向入力：高速小ジャンプ
- ジャンプ：大ジャンプ
- STEP：変形回避（空中では着地まで1回）
- 攻撃が当たる瞬間にジャンプ：ジャスト跳ね返り

ZIPを展開し、`index.html` と `README.md` をGitHubリポジトリ直下へ置いてください。
