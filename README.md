# スライム・キックオフ2 v1.4α

GitHub Pagesで動作する、画像素材・外部ライブラリ不要のHTML5ゲームです。

## 追加：スライムモード

開始画面で「スライムモード」を選択すると、スライムを直接操作します。

- 方向キー／WASD／左スティック：入力した方向へ小ジャンプ
- Xキー／黄色ボタン：入力方向へ大ジャンプ
- 入力方向がない場合、大ジャンプは直前に向いていた方向へ跳びます
- コート内の反跳陣へ着地すると踏破済みになります
- 全反跳陣を踏むとクリアです
- 踏破済みの反跳陣は黄色へ変化します
- スライムは滑らず、各ジャンプの着地後に完全停止します

## 対戦モード

従来の人間対CPU戦も開始画面から選択できます。

- 移動：方向キー／WASD／左スティック
- 弱攻撃：Zキー／赤ボタン
- 強攻撃：Cキー／青ボタン
- ジャンプ：Xキー／黄色ボタン
- 3点先取

## GitHub Pages

ZIPを展開し、`index.html` と `README.md` をリポジトリ直下へアップロードしてください。GitHub Pagesの公開元を対象ブランチのルートに設定すると、そのまま公開できます。
