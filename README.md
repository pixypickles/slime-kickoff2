# スライム・キックオフ2 v1.4.1α

GitHub Pagesでそのまま動く、HTML Canvas製の試作ゲームです。

## モード

### 対戦モード
人間同士でスライムを相手側の村へ押しつけます。

### スライムモード
操作するのはスライムです。

- 方向入力：その方向へ小ジャンプ
- ジャンプボタン：大ジャンプ
- 全ての反跳陣を踏むとクリア
- 村人1人がスライムの着地点を予測して追いかけ、キックしてきます
- 蹴られてもゲームオーバーにはならず、飛ばされた先で反跳陣を踏むこともできます
- 反跳陣の踏破判定は見た目より約25〜30%広めです

## クリアランク

- S：被キック0回
- A：1〜2回
- B：3〜5回
- C：6回以上

## 公開方法
ZIPを展開し、`index.html` と `README.md` をGitHubリポジトリ直下へアップロードしてGitHub Pagesを有効にしてください。
