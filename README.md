# スライム・キックオフ2 v1.3α

GitHub Pagesでそのまま動作する、HTML Canvas製のスマートフォン向け試作ゲームです。

## 世界観

前作から数年後、競技参加者の魔法は年々エスカレートし、スライム競技は魔法バトルへ変わってしまいました。

そこで大魔導師はコート全体をアンチマジックフィールドに指定。魔法による激しさが消え、コートには次第に雑草が生え始めます。

ただし競技が静かになりすぎたため、大魔導師は気まぐれで、強い反発力を生む魔法装置「反跳陣（はんちょうじん）」を各地へ設置しました。選手たちは反跳陣を利用したアクロバティックな技で、少し臭うスライムを隣村へ押しつけ合います。

## v1.3αの変更

- キャラクターを約15%小型化
- 胴体を短くし、頭身を調整
- 待機時の腕をファイティングポーズへ改善
- サマーソルトに全方向の大きめ円形当たり判定を追加
- パンチを含む全攻撃のノックバックを強化
- 強攻撃のヒットストップと画面揺れを強化
- 「トランポリン」の呼称を「反跳陣」へ変更
- 雲スライム由来の設定を削除し、大魔導師が設置した設定へ変更

## 操作

- 移動：画面左スティック / WASD / 矢印キー
- 弱攻撃：赤ボタン / Z
- 強攻撃：青ボタン / C
- ジャンプ：黄ボタン / X

## 公開方法

ZIPを展開し、`index.html` と `README.md` をGitHubリポジトリ直下へアップロードしてください。GitHub Pagesの公開元を対象ブランチのルートへ設定すると遊べます。
