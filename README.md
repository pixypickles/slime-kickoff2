# スライム・キックオフ2 v1.5.1α

GitHub Pagesでそのまま動作する、HTML Canvas製のスマートフォン対応プロトタイプです。

## v1.5.1α の主な変更

スライムモードに難易度選択を追加しました。

- **のんびり**：村人1人。移動・先読み・攻撃頻度が控えめ。反跳陣の踏破判定も広め。
- **ふつう**：v1.4.3α相当の標準バランス。村人1人。
- **むずかしい**：村人2人。少し先回りし、左右から挟むように追跡。
- **大魔導師級**：村人2人。移動・先読み・攻撃判断が最も積極的。

難易度が変わっても、次の操作感は全難易度で共通です。

- 小ジャンプの距離と速度
- 大ジャンプの高さ
- STEPのクールタイムと無敵時間
- ジャスト跳ね返りの受付時間
- ノックバック量
- ボタン配置

選んだ難易度は端末内へ保存され、次回起動時にも引き継がれます。クリア時には難易度、タイム、被キック回数、ランクを表示します。

## モード

### 対戦モード

人間同士でスライムを隣村へ押しつける3点先取の対戦です。

### スライムモード

スライムを操作し、村人の攻撃を避けながらすべての反跳陣を踏破します。

- 方向入力：高速小ジャンプ
- ジャンプ：大ジャンプ／攻撃直前ならジャスト跳ね返り
- STEP：地上では平べったい回避、空中では軌道変更

## GitHub Pages

ZIPを展開し、`index.html` と `README.md` をリポジトリ直下へ配置してください。外部画像・外部ライブラリは使用していません。
