# スライム・キックオフ2 Rebuild Prototype v0.6

GitHub Pagesでそのまま動作する、画像素材・外部ライブラリ不要のHTML5 Canvas試作です。

## v0.6

操作・攻撃・キャラクターモーションを大幅に作り直しました。

### ボタン

- 移動：画面左スティック / WASD / 矢印キー
- 弱攻撃：赤ボタン / Z
- 強攻撃：青ボタン / C
- ジャンプ：黄ボタン / X

### 攻撃の変化

- スライムが地上 + 弱：その場で膝を一度曲げて素早く蹴る
- スライムが地上 + 強：軸足を一歩踏み込み、大きく振り抜く
- スライムが空中 + 弱：アッパーカット
- スライムが空中 + 強：片足で踏み切る二段蹴り
- 自分がジャンプ中 + 弱：ヘディング
- 自分がジャンプ中 + 強：空中で一回転して後ろ蹴り

### 維持している仕様

- スライムはジャンプか攻撃を受けた時だけ移動
- 着地後は完全停止
- 滑らない、転がらない
- 楕円形の異次元コート
- 段差、シーソー、草、木、石
- 村と村で、無害だが少し臭うスライムを押しつけ合う設定
