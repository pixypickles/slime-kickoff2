# スライム・キックオフ2 試作版 v0.1

GitHub Pagesへそのままアップロードできる、単一HTMLのゲーム試作です。

## 今回の試作内容

- 特殊能力なしの人間キャラクター
- 顔は目だけ
- 太い黒い輪郭線
- 少し大きめの頭と丸みのある、やや可愛いデザイン
- 肩・肘・腰・膝を使った簡易関節アニメーション
- 5段階のゆっくりしたキックモーション
- スライムはジャンプ移動のみ
- スライムは滑らない、転がらない
- キック後も弧を描いて軽く飛び、着地時に完全停止
- ごく低確率で極小バックステップ回避
- スマホ用仮想スティックとキックボタン
- PCでは矢印キーまたはWASD、Spaceで操作

## GitHub Pagesで公開する方法

1. 新しいGitHubリポジトリを作成します。
2. ZIPを展開し、中の `index.html` と `README.md` をリポジトリ直下へアップロードします。
3. GitHubの `Settings` → `Pages` を開きます。
4. `Deploy from a branch` を選び、`main` / `root` を指定して保存します。

## ファイル構成

- `index.html` ゲーム本体
- `README.md` 説明

外部画像や外部ライブラリは使用していません。
