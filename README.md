# スライム・キックオフ2 Rebuild v0.6.6

GitHub Pagesで動作する単一HTMLの試作版です。

## 今回の修正

- 待機姿勢をファイティングポーズへ変更
- ストレートは肩から拳まで真っ直ぐ伸ばす描画へ変更
- 横蹴りは脚全体をやや上向きに一直線へ調整
- ジャンプ強の二段蹴りは、蹴り脚をより遠くまで真っ直ぐ伸ばすよう調整

## 操作

- 移動: 画面左スティック / WASD / 矢印キー
- 弱攻撃: 赤ボタン / Z
- 強攻撃: 青ボタン / C
- ジャンプ: 黄ボタン / X

ZIPを展開し、`index.html` と `README.md` をGitHubリポジトリ直下へアップロードしてください。
