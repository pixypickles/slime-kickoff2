# スライム・キックオフ2 Rebuild v0.6.3

GitHub Pages向けの単一HTML試作です。`index.html` をリポジトリ直下へ置いてください。

## v0.6.3 修正

- 浮いたスライムへの弱攻撃を、拳が腰下から頭上へ突き上がるアッパーカットへ修正
- 浮いたスライムへの強攻撃を、1発目の脚を下ろしながら反対脚で蹴り上げる二段蹴りへ修正
- ジャンプ強攻撃の前宙回転を廃止
- ジャンプ強攻撃は、頭から足までの縦軸を中心に1回転してから跳び後ろ蹴りを出す表現へ変更
- キャラクター、スライム、背景はCanvas描画のみ。外部画像素材なし

## 操作

- 移動：画面左スティック／WASD／矢印キー
- 弱攻撃：赤ボタン／Z
- 強攻撃：青ボタン／C
- ジャンプ：黄色ボタン／X
