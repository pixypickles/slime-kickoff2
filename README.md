# スライム・キックオフ2 v1.1α

GitHub Pagesで動作する、スマホ対応のHTML5 Canvas試作です。

## v1.1αの変更

- 段差とシーソーを一旦削除
- 木、石、草むらは維持
- コートを少しコンパクトに調整
- スライムをほぼ円形の丸いシルエットへ変更
- 小型トランポリンを3か所追加
- 人間がトランポリンへ着地すると高く跳ねる
- スライムがトランポリンへ着地すると大きく跳ねる
- スライムは滑らず、転がらず、ジャンプまたは攻撃の衝撃でのみ移動

## 操作

- 移動：画面左スティック / WASD / 矢印キー
- 弱攻撃：赤ボタン / Z
- 強攻撃：青ボタン / C
- ジャンプ：黄色ボタン / X

ZIPを展開し、`index.html` と `README.md` をリポジトリ直下へ置いてください。
