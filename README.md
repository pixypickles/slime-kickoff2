# スライム・キックオフ2 Prototype v0.2

GitHub Pagesでそのまま動く、画像素材・外部ライブラリ不要のHTML5 Canvas試作です。

## v0.2で追加・改善した内容

- 膝と肘を使った歩行アニメーション
- 歩行時の足運び、身体の上下動、腕振り
- 5段階のキックと実際の踏み込み移動
- 接触時の画面停止、揺れ、スライム変形
- スライムの着地時のつぶれ表現
- スライムはジャンプまたは蹴られた時だけ移動し、着地後は完全停止
- ごく稀な極小バックステップ回避
- CPU対戦
- 左右ゴールと3点先取ルール
- スマートフォン用仮想スティックとキックボタン
- キーボード操作（WASD／矢印＋Space）

## GitHub Pagesへの公開

1. ZIPを展開します。
2. `index.html` と `README.md` をリポジトリ直下へアップロードします。
3. GitHubの Settings → Pages で、公開元を main ブランチの root に設定します。
