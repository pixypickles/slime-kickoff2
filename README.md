# スライム・キックオフ2 Prototype v0.5

GitHub Pagesで動作する、画像素材・外部ライブラリ不要のHTML5 Canvas試作です。

## v0.5の追加内容

- スライムの通常ジャンプ、キック、ヘディングの飛距離と高さを拡大
- ジャンプ操作を追加
- ジャンプ中のキック入力をヘディングへ変更
- 段差を追加。歩行では越えられず、ジャンプで登れる
- シーソーを追加。スライムが着地すると大きく跳ねる
- 木と石を障害物として追加
- 草むらでは人間の移動速度が低下
- 楕円形の異次元コートと村同士の設定を維持

## 操作

- 移動：画面左スティック / WASD / 矢印キー
- キック：画面右の赤ボタン / Space
- ジャンプ：画面右の黄ボタン / X
- 空中でキック：ヘディング

## GitHub Pagesへの公開

ZIPを展開し、`index.html` と `README.md` をリポジトリ直下へアップロードしてください。GitHub Pagesの公開元を対象ブランチのルートに設定すると遊べます。
